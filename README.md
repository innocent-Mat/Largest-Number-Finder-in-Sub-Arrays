# Largest Number Finder in Sub-Arrays

## Overview

Largest Number Finder in Sub-Arrays is a JavaScript application that identifies the largest number in each sub-array of a multidimensional array and returns them in a new array.

This project is useful for learning array manipulation, nested loops, and basic algorithm design in JavaScript.

## Features

- Finds the largest number in each nested array.
- Returns the results as a new array.
- Simple and beginner-friendly implementation.
- Demonstrates JavaScript fundamentals.

## Technologies Used

- JavaScript (ES6)

## Installation

1. Clone the repository:

   git clone https://github.com/innocent-Mat/Largest-Number-Finder-in-Sub-Arrays.git

2. Navigate to the project folder:

   cd largest-number-finder

3. Run the JavaScript file:

   node script.js
